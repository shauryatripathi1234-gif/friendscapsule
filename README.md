# 🗝️ The Tripathi (त्रिपाठी) Archive

> A whimsical, HackMIT-inspired private friendship capsule & secret vault created by **Shaurya Tripathi (त्रिपाठी)**.

---

## 🌟 Overview

The **Tripathi Archive** is an intimate, quirky memory-capsule web application designed for Shaurya Tripathi and his inner circle. Rather than sharing filtered updates on superficial social media feeds, friends visit this space to:
1. **Snap a photo** using the retro live photobooth studio (or upload a candid from their phone).
2. **Apply vintage film filters** (Warm 90s, Golden Hour, Retro Grain, Noir B&W) and custom **त्रिपाठी** stickers.
3. **Pen a 20-word whisper** (strictly enforced maximum 20 words on a typewriter postcard).
4. **Seal it into the vault** with a wax stamp and celebratory confetti explosion.
5. **Private Vault Access**: Only Shaurya Tripathi holds the secret golden key and PIN to open the vault and view the corkboard scrapbook of all polaroid memories.
6. **DHH Cassette & AirPods Station**: Stream random bangers from **Seedhe Maut, KR$NA, Karma, WhySoKai, and Ikka** via embedded YouTube without any login prompts.

## 🚀 Quick Start

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/<your-username>/friend-capsule.git

# Enter project directory
cd friend-capsule

# Install dependencies
npm install
```

### 3. Run Locally
```bash
npm start
# Or for live development
node server.js
```
Open **http://localhost:3000** in your browser.

## 🔐 Keeper's Master Vault
- **Trigger**: Click the floating Golden Key (**"त्रिपाठी'S KEY 🗝️"**) in the top right navbar.
- **Default PIN**: `2026`
- **Features Inside Vault**:
  - Full corkboard scrapbook with tilted polaroids.
  - Detail inspector modal with high-res photo, stickers, and note.
  - **"Save Polaroid"**: Renders and downloads high-resolution PNG keepsake.
  - **Slideshow Mode**: Fullscreen ambient photo presentation.
  - **Export All**: Download complete JSON backup.
  - **Change PIN**: Update master security code anytime.
